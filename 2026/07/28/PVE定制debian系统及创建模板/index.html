    这几段做的

    部分 作用
    GRUB OS_PROBER 避免虚拟机里探测其它系统导致启动异常
    serial-getty@ttyS1 额外串口登录（PVE 仍需 --serial0 提供 ttyS0）
    去 deb-src / 关 mirrorlist 自动覆盖 源配置更可控
    99-internal-password.conf sshd：允许 root + 密码 + 键盘交互
    99-ssh-pwauth.cfg cloud-init：别在首启再关掉密码认证、不禁用 root
    --update + --install 升级并装常用工具 / qemu-guest-agent
    清理 + machine-id 模板克隆更干净
